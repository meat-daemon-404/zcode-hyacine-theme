# Changelog

All notable changes to **zcode-hyacine-theme** are documented in this file.

## [1.1.0] - 2026-11-20

### Added
- **Package Manifest (`package.json`)**: Added standard package metadata and file whitelist for theme distribution.
- **English Documentation (`README.en.md`) & `CHANGELOG.md`**: Added bilingual documentation covering the palette semantics, ZCode CDP theme, and Codex CLI / Windows Terminal installer.

## [1.0.0] - 2026-09-24

### Added
- **ZCode Desktop UI Theme (`zcode/`)**: Translucent dusk-indigo surfaces, four-tier lavender typography, Hyacine palette for usage charts/heatmaps, and `MutationObserver` Hyacine voice greeting overrides.
- **Codex CLI & Windows Terminal Adaptation (`codex/`)**: `.tmTheme` syntax highlighting, Windows Terminal scheme + profile installer, and launch helper.
- **Icon & Wallpaper Suite (`icon/hyacine.ico`, `wallpapers/hyacine-static.jpg`)**: Custom rounded desktop icon and 2560×1440 static wallpaper.
